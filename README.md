# Museum of the Year 3000

make.fun bounty entry: a program that writes one line — the museum label a
museum in the year 3000 puts beside an ordinary object from today.

## The entry

> Do Not Disturb (tablet, c. 2025): hung on doors to ward off the cleaning spirits, who arrived each morning regardless.

- Characters: 118 (limit 200)
- Object: a hotel "Do Not Disturb" door hanger, misread by the year-3000
  curators as a prayer tablet meant to repel the cleaning spirits — who
  showed up every morning anyway.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt`. Deterministic: every run
writes exactly the same line.
